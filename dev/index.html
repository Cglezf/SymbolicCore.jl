SymbolicCore

Módulo básico para manipulación simbólica de expresiones algebraicas en Julia.

Este paquete forma parte del curso profesional de desarrollo en Julia. Incluye una representación simbólica mínima y extensible con soporte para evaluación, impresión y simplificación de expresiones aritméticas.

🧠 Tipos simbólicos

Los siguientes tipos representan expresiones simbólicas:

SymbolicCore.Constant — Type
Constant(value::Float64)

Representa una constante numérica simbólica. Ejemplo: Constant(3.14)

source
SymbolicCore.Variable — Type
Variable(name::Symbol)

Representa una variable simbólica identificada por un nombre. Ejemplo: Variable(:x)

source
SymbolicCore.BinaryOp — Type
BinaryOp(op::Symbol, left::AbstractSymbolic, right::AbstractSymbolic)

Representa una operación binaria simbólica. Ejemplos: x + y, a * b, Variable(:x) + Constant(2.0)

source

⚙️ Evaluación numérica

Funciones para evaluar expresiones simbólicas con un entorno numérico (Dict{Symbol, Float64}):

SymbolicCore.evaluate — Function
evaluate(expr::Constant, env::Dict)

Devuelve el valor numérico de la constante.

source
evaluate(expr::Variable, env::Dict)

Busca el valor de la variable en el entorno env. Lanza un error si no se encuentra.

source
evaluate(expr::BinaryOp, env::Dict)

Evalúa recursivamente ambos operandos y aplica el operador binario (+, *, etc.).

source

🖨️ Impresión simbólica

Sobrecarga de Base.show para imprimir expresiones de forma legible:

Base.show — Method
show(io::IO, c::Constant)

Imprime el valor numérico de la constante, por ejemplo: 3.14

source
Base.show — Method
show(io::IO, v::Variable)

Imprime el nombre de la variable simbólica, por ejemplo: x

source
Base.show — Method
show(io::IO, b::BinaryOp)

Imprime la operación binaria en notación infija con paréntesis. Ejemplo: (x + 2.0)

source

🧹 Simplificación simbólica

Reducción de expresiones cuando existen constantes computables:

SymbolicCore.simplify — Function
simplify(expr::Constant) -> Constant

Retorna la constante sin cambios. Las constantes ya están en su forma más simple.

source
simplify(expr::Variable) -> Variable

Retorna la variable sin cambios. Las variables no pueden simplificarse sin un valor.

source
simplify(expr::BinaryOp) -> Expr

Simplifica recursivamente los operandos de una expresión binaria.

  • Si ambos operandos son constantes, evalúa el resultado directamente.
  • Si se trata de una suma con 0 o multiplicación por 1, retorna el otro operando.
  • Si se trata de multiplicación por 0, retorna Constant(0.0).

Devuelve una nueva expresión simplificada o el resultado evaluado si es posible.

source
